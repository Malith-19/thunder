# Try In Your Own App

Each walkthrough below configures <ProductName /> for one B2C use case and points you at the SDK documentation for the integration code. Your application handles the UI; <ProductName /> handles identity.

:::tip Already following Try It Out?
This path is for integrating <ProductName /> into your own app. If you'd rather see the use cases running against a pre-built sample, see [Try It Out](../try-it-out).
:::

## Prerequisites

- <ProductName /> running locally. Follow [Get <ProductName />](/docs/next/guides/getting-started/get-thunderid) if you haven't already.
- A consumer app integrated with <ProductName /> for sign-in. If you are starting fresh, complete the quickstart for your framework under [Connect Your Application](/docs/next/guides/getting-started/connect-your-application/) before continuing here.

## Coverage

Each walkthrough supports four integration approaches from [Solution Patterns](../solution-patterns). Redirect-based is available now; the others follow as SDK support ships.
